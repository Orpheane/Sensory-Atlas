# Sensory Atlas - deployment instructions

## Repository
Public GitHub repository: https://github.com/Orpheane/Sensory-Atlas

The code for this static concept showcase lives in the repository root. It does not require a build step.

## Enable GitHub Pages
1. Open https://github.com/Orpheane/Sensory-Atlas/settings/pages
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** as the branch and **/(root)** as the folder.
4. Save the setting.
5. Once GitHub reports a successful deployment, use https://orpheane.github.io/Sensory-Atlas/

GitHub Pages may need to be enabled in repository settings; uploading this code alone does not guarantee a live site.

## Devpost
- Code/project link: https://github.com/Orpheane/Sensory-Atlas
- Try it out (after verified live): https://orpheane.github.io/Sensory-Atlas/

The demo is illustrative and uses entirely fictional venues and ratings. No working community location database is claimed.

## Built with
The showcase uses HTML, CSS, JavaScript, GitHub, and AI-assisted visual exploration. MapLibre, React, Supabase, and other future-platform technologies are not yet implemented.
