# Contributing to Sensory Atlas

Thank you for considering a contribution. Sensory Atlas is an early-stage accessibility project and its current demonstration uses **fictional places and sensory ratings**. Please do not submit real people's medical information, private location histories, access credentials, or unverified claims about real venues.

## Where to start

1. Read the [README](README.md), [design principles](docs/PRINCIPLES.md), and [roadmap](docs/ROADMAP.md).
2. Open an issue describing a bug, accessibility barrier, suggested improvement, or proposed feature before embarking on a major change.
3. For small changes, fork the repository, create a focused branch, and submit a pull request that explains what changed and why.
4. Include manual testing notes, especially keyboard access, screen-reader output where possible, reduced motion, color contrast, responsive behavior, and whether the interface stays calm by default.
5. Keep the demo's sample places and scores clearly fictional.

## Running the demo locally

No installation or build process is required. Open `index.html` in a modern browser or serve the repository root with a local static server. The official demonstration is deployed using GitHub Pages. It has no live map data, user accounts, or backend service.

## Community and privacy

Please be patient and respectful of different sensory experiences and access needs. Avoid treating a particular rating as objective proof that a place is safe or comfortable for everyone. When reporting security or privacy problems, do not paste confidential data into a public issue.
